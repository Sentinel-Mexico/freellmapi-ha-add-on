# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of OpenSpeedTest as a Home Assistant add-on.
- Based on the official OpenSpeedTest Docker image.
- Web interface accessible via Home Assistant Ingress sidebar.
- Direct access on port 3000 for any browser on the network.
- Download, upload, ping, and jitter measurements.
- Zero configuration required.
- Multi-architecture support: amd64 and aarch64.
