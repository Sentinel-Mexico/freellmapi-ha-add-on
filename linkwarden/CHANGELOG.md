# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of Linkwarden as a Home Assistant add-on.
- Based on Linkwarden v2.16.3.
- Web interface accessible via Home Assistant Ingress sidebar.
- Direct access on port 3000 for browser extension connections.
- Embedded PostgreSQL database with persistent storage.
- Automatic web page archival with screenshots and PDF snapshots.
- Configurable registration, email (SMTP), and auth secret.
- Multi-architecture support: amd64 and aarch64.
