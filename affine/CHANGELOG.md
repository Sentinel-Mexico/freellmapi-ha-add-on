# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of AFFiNE as a Home Assistant add-on.
- Based on AFFiNE stable release image.
- Web interface accessible via Home Assistant Ingress sidebar.
- Direct access on port 3010 for desktop and mobile clients.
- Embedded PostgreSQL database with persistent storage.
- Embedded Redis for caching and real-time sync.
- Documents, whiteboards, and databases in one workspace.
- AI Copilot with bring-your-own-key (BYOK) support.
- Configurable server name, email (SMTP), and log level.
- Multi-architecture support: amd64 and aarch64.
