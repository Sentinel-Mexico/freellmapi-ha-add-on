# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of Vaultwarden as a Home Assistant add-on.
- Based on Vaultwarden 1.33.2 (Bitwarden-compatible server).
- Web vault accessible via Home Assistant Ingress sidebar.
- Direct access on port 8080 for Bitwarden client connections.
- SQLite database with persistent storage.
- Configurable signups, admin panel, SMTP, and domain settings.
- WebSocket support for real-time sync across devices.
- Multi-architecture support: amd64 and aarch64.
