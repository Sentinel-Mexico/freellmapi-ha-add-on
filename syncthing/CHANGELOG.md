# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of Syncthing as a Home Assistant add-on.
- Based on Syncthing v1.29.2.
- Web interface accessible via Home Assistant Ingress sidebar.
- Direct access on port 8384 for browser and API clients.
- Sync protocol on port 22000 (TCP and QUIC).
- Local device discovery on port 21027 (UDP).
- Host networking for optimal peer-to-peer performance.
- Access to Home Assistant shared, media, and backup directories.
- Optional GUI authentication (username and password).
- Multi-architecture support: amd64 and aarch64.
