# Changelog

## 1.0.0 — 2026-09-18

### Added

- Initial release of Netdata as a Home Assistant add-on.
- Based on Netdata v2.11.0.
- Real-time monitoring dashboard accessible via Home Assistant Ingress sidebar.
- Direct access on port 19999 for browsers and API clients.
- Persistent time-series database (dbengine) stored in add-on data.
- System metrics: CPU, memory, disk, network, processes.
- Container and application monitoring.
- SYS_PTRACE capability for detailed process monitoring.
- Multi-architecture support: amd64 and aarch64.
